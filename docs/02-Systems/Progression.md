# Progression

Four parallel trees, fed by delivery income and by [[Science]].

| Tree | Axes |
|---|---|
| [[Rover]] | Power, suspension, racks, flare shield, tyres/tracks, winch, autopilot |
| Suit | O₂, thermal, shielding, mobility, exo-assist, sensors |
| Tools | Survey scanner, sampler, cutter, welder, anchor/zip launcher |
| [[The-Lander]] | Fuel capacity, engine efficiency, refinery, workshop, storage |

Research is the **only** route to the deepest tier, so the science thread can
never be skipped by a player who only hauls.
